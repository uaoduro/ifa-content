# IFA Content

Content planner for IFA in Madinah: calendar, scripts, ready-to-film list and tasks for Umar and Khalid.

Live: https://uaoduro.github.io/ifa-content/

Syncs through the `ifa_items` table and the `ifa_pull` / `ifa_push` functions in the halaqah-competition Supabase project. Nothing else in that project is used.
